# Godot-Block-Puzzle

Quebra-cabeça de Blocos, desenvolvido para ser uma ferramenta lúdica no desenvolvimento de habilidades cognitivas.

O objetivo do jogo vai além do entretenimento, atuando como um estímulo para o raciocínio lógico, planejamento espacial e resolução de problemas. A mecânica de encaixe de blocos em um grid incentiva o jogador a pensar à frente e a otimizar o espaço de forma estratégica.
